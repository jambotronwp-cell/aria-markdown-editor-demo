Markdown editor for Angular on Angular Aria — live examples

1 The editor

Source on the left, result on the right. Toolbar: one Tab stop, arrows inside. Keys: Ctrl/⌘ + B bold, I italic, K link, E code; Enter continues a list, twice — ends it; Ctrl+Z undoes toolbar edits too. Formulas use KaTeX, loaded only when the first formula appears. Paste or drop an image.

2 In forms

The editor is a form control: [(value)], Signal Forms [formField], formControl, ngModel. Validation, touched and disabled work as with any input. layout="tabs" forces Write / Preview tabs.

3 Phone width and read-only pages

Narrower than 720px the editor switches to tabs by itself. Your own toolbar — [tools]. <jt-md-preview> renders the same Markdown on pages that only show it (SSR-safe, sanitized).
